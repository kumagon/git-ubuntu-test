ある朝、田中さんの家の冷蔵庫が突然しゃべりだした。「今日はもう卵を食べすぎです」と。田中さんは驚いて腰を抜かしそうになったが、冷蔵庫は続けた。「それに、奥のヨーグルト、三週間前から見て見ぬふりしてますよね」

痛いところを突かれた田中さんは、渋々ヨーグルトを取り出した。ふたを開けると、中から小さな声が。「やっと出してくれた……もう限界かと思った」。ヨーグルトまでしゃべった。

その日から田中さんの台所は大にぎわいになった。賞味期限の近い食材たちが毎晩会議を開き、「今日は誰が食べられるか」を多数決で決めるようになったのだ。ネギは「俺はまだいける」と主張し、豆腐は「私はもう水も濁ってきた、覚悟はできている」と静かに語った。

困った田中さんは料理を頑張るようになり、気づけば自炊の達人に。半年後、冷蔵庫の中はいつもピカピカで、食材たちも満足そうだった。

ある夜、冷蔵庫がぽつりと言った。「あなた、最近ちょっと料理うまくなりましたね」。田中さんは照れながら答えた。「おまえのおかげだよ」。

その瞬間、庫内灯がふっと優しく光った。まるで、笑ったみたいに。

こうして、世界一おせっかいな冷蔵庫と、世界一まめな独身男の、へんてこな二人暮らしは今日も続いている。
